### Top 8 metrics to track on a BigQuery dashboard

- Number of in flight jobs
- Queries in flight
- Average of query execution times
- Sum of Squared Deviation for query execution times
- Number of scanned bytes
- Scanned bytes billed
- Number of BigQuery slots currently allocated for project

### Top 8 Presto monitoring metrics

- Number of failed queries
- Maximum time spent in YoungGen Garbage Collection
- Maximum time spent in OldGen Garbage Collection
- Number of worker nodes in the Presto cluster
- Query execution latency
- Number of submitted queries
- Input data rate in 5 minutes
- Number of active query executors

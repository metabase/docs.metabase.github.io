## What is a filter widget?

![Two filter widgets on a dashboard, allowing people to filter results by Customer ID or Customer Name.](/glossary/images/filter-widget/filter-widget.png)

A **filter widget** is a UI element on a dashboard or SQL query where you can input a value or select one from a menu to filter results, like selecting `CA` to limit results to the state of California.

## What is the Sample Database?

The Sample Database is a small database that ships with Metabase so you can start asking questions and creating dashboards before you connect to your database. The Sample Database contains four tables: `Orders`, `People`, `Products`, and `Reviews`. It’s an **H2** database, and you’ll see the Sample Database used in examples all over [Learn](/learn/).

## What is a field filter?

A field filter is a special variable that you can use in SQL queries that lets you create a "smart" filter widgets.  You can connect your SQL-built charts to dashboard filters. If you write queries in SQL, you should definitely learn how these work, as you can do things like create pre-populated dropdowns in your filter widgets.

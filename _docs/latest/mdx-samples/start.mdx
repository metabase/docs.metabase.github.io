# MDX samples

This page is written in MDX. It pulls in a Liquid include directly and an MDX partial that nests another partial.

## Liquid include

Equivalent to `{% include plans-blockquote.html feature="Duration caching policy" %}`:

<LiquidInclude src="plans-blockquote.html" feature="Duration caching policy" />

Enterprise-only, plural variant:

<LiquidInclude src="plans-blockquote.html" feature="Custom caching rules" is_plural={true} enterprise-only={true} />

# Which databases does Metabase support?

The following databases are officially supported by Metabase:

- BigQuery
- Druid
- Google Analytics
- H2
- MongoDB
- MySQL/MariaDB
- PostgreSQL
- Presto
- Amazon Redshift
- Snowflake
- Spark SQL
- SQLite
- SQL Server

You may find some [community-built database drivers](../../developers-guide-drivers.html) for databases that we do not currently support - and you are always welcome to build your own!

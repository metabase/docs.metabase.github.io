Export your instance configuration and content as YAML files

Keep multiple environments in sync with serialization — an easy way to convert content in your instance to YAML files for self-hosted instance portability.

  • Save configuration settings to a file to spin up new instances from a template.
  • Test things out in staging before pushing to production.
  • Enable git-based workflows for content moderation.

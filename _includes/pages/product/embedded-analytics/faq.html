For developers: FAQ

For more info on how it works and getting set up fast, head to the docs or check out the Quickstart.

How does Metabase perform when embedded in our app?

Metabase is optimized for speed and runs live on your data—no waiting on extracts or syncing. Charts and dashboards load quickly, and performance scales with your infrastructure.

How customizable is it?

White label your embedded charts and interactive dashboards with no code and enough tools to get it where you need it without overwhelm. Use the React SDK for custom analytics components that integrate with your UI with CSS theming options.

Is it secure enough to ensure my customers never see another customers' data?

Absolutely. Metabase is up to date with first-class compliance, like SOC2 Type II, GDPR, and CCPA. Fine-grained permissions, multi-tenancy, usage analytics and audit logs, and self-hosting available.

Can we start simple and transition to the SDK later?

Yes, and that’s a common path. Modular Embedding is a JavaScript library built on top of the React SDK to build and ship quickly with no-code, validate demand, then move to the SDK for a more integrated, branded experience. Metabase supports both workflows with minimal friction.

When Cloud isn't the right choice

If you need any of the following, self-hosting is a better way to go:

  • {% include svg-icons/list-dot-icon.html %}

    An air-gapped environment

  • {% include svg-icons/list-dot-icon.html %}

    You're using a community or custom driver to connect to your data source

  • {% include svg-icons/list-dot-icon.html %}

    A custom build of Metabase

  • {% include svg-icons/list-dot-icon.html %}

    Data stored outside of the United States. Metabase Cloud can now be hosted in the US, Europe, Latin America, or Asia-Pacific!

  • {% include svg-icons/list-dot-icon.html %}

    Or if you have specific regulations about how you run your software (like HIPAA)

But if none of the above apply to you, Metabase Cloud will save you time, money, (maybe even tears).

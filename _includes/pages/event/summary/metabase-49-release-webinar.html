Summary

In this webinar hosted by Product Marketing Manager, Jess, Metabase Product Managers, Conor Dewey and Luiz Arakaki presented new features in Metabase 49.

Conor started by showing slick new ways to create and edit dashboards, with section templates, buttons to duplicate and swap out cards, and add filters that appear only on relevant tabs.

He then showed how to add more comparisons to trend charts and customize date ranges.

Luiz took the floor next to showcase new features for using Metabase in development, such as API keys for authentication and serialization.

Next up, Jess showed how non-technical users can bring data into Metabase via CSV upload and maintain models with evolving data with the new append function.

Finally, the Q&A session gave participants to ask about features shown in Metabase 49 and what’s coming in 50 and beyond.

Summary

This webinar covered how to use Metabase for embedded analytics in customer-facing applications. Louis, a success engineer, demonstrated how to embed Metabase, focusing on three main embedding types: interactive embedding, static embedding, and public embedding.

Key points:

  • Interactive Embedding: Provides full Metabase functionality directly within an application. Users don't need to access Metabase separately, and it supports features like user provisioning, role-based security, and customization. This is ideal for those needing an advanced embedded analytics tool for applications.
  • Static Embedding: Embeds dashboards or specific questions with limited interactivity, such as filter options. This is included in the free version of Metabase and is a simple solution for basic embedded analytics dashboards.
  • Public Embedding: Allows sharing of dashboards or questions publicly, without requiring authentication. This is useful for embedding analytics on websites or blogs for public access.

If you're looking to implement embedded analytics solutions with an open-source tool like Metabase, this webinar is for you. Whether you need embedded dashboards, embedded data visualization tools, or examples of embedded analytics in action, the session covers it all. It’s suitable for businesses of any size, from startups looking for scalable embedded analytics platforms to those seeking alternatives like Power BI embedded reports.

Summary

In this webinar hosted by Technical Communicator, Alex Yarosh, Metabase Product Managers, Luiz Arakaki, Conor Dewey, Gleb Sologub, and Alberto Perdomo presented new features in Metabase 53.

Luiz introduced key enhancements, including the ability to save questions directly to dashboards, preemptive caching for faster performance, and new model details now accessible in the sidebar.

Next, Conor showcased improvements to content sharing, such as dynamic iframe and link cards, as well as support for paginated PDFs, making it easier to navigate and distribute reports.

Gleb followed with updates to the query builder, highlighting improvements that streamline data exploration, along with enhanced latitude/longitude binning for better geospatial analysis.

Finally, Alberto Perdomo shared exciting news about our SDK. While it’s been a recurring topic in past webinars, this time, attendees were the first to hear that the SDK is officially coming out of beta this week!

The session wrapped up with a Q&A led by Alex Yarosh, where attendees had the opportunity to dive deeper into the latest features and ask their pressing questions. Read more about it in our release announcement.

Thanks to everyone who joined—stay tuned for more updates in the next release!
